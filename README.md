# End to End AWS DevOps Project Implementation
This repo contains End to End DevOps Implementation on a E-Commerce project wherin I have performed:

- Infrastructure setup on AWS (S3 bucket, Dynamo DB, VPC, EKS) using terraform modules.
- Set up Terraform remote backend and locking with AWS S3 Bucket and DynamoDB.
- Containerization of 3 diffierent micro-services using docker and implemented Docker best practices like multi-stage builds.
- Deployed multi-microservice application to AWS EKS cluster using YAML manifest.
- Implemented CI/CD using github actions and Argo CD follwing devsecOps best practices.
- Exposed the frontend securely to users by mapping Route 53 DNS records with a domain provider.
